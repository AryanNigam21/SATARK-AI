# SATARK AI
A Bharat-first investor safety assistant for detecting scam and misinformation indicators.

## Run
Open `index.html` in any browser.

## Scope
This prototype analyzes suspicious financial content using transparent rule-based indicators. A production version can add multilingual NLP/LLM analysis, verified public sources, URL reputation checks, and voice support.

## Safety
SATARK AI is an awareness and scam-resilience tool. It does not provide investment advice, stock predictions, trading signals, or buy/sell recommendations.
